Vrinda Store Sales Analysis – Excel Dashboard

Project Overview

This project focuses on analyzing Vrinda Store's sales data using Microsoft Excel. The objective is to transform raw sales data into meaningful business insights through data analysis, visualization, and an interactive dashboard.

The dashboard provides an overview of sales performance, order trends, customer demographics, sales channels, and order status.

 Dashboard Preview

![Vrinda Store Sales Dashboard](dashboard.png)

Key Performance Indicators (KPIs)

- Total Sales: 21,176,377
- Total Orders: 31,047
- Average Order Value: 682

Dashboard Features

The interactive dashboard includes the following analysis:

1. Monthly Sales & Order Trend – Tracks monthly sales and order volume.
2. Order Status Breakdown – Analyzes delivered, cancelled, returned, and refunded orders.
3. Top 5 States by Sales – Identifies the highest-performing states.
4. Sales Channel Analysis – Compares order contribution across different sales channels.
5. Gender-wise Order Analysis – Compares order distribution between men and women.
6. Age Group & Gender Analysis – Examines customer order distribution across different age groups.

Key Business Insights

- Women contribute approximately 64% of total orders.
- Amazon contributes the highest order share at 35.48%.
- Maharashtra is the leading state by sales, contributing approximately 2.99M.
- Approximately 92.25% of orders are delivered successfully.
- Adults represent the largest age-group contribution to orders.

Interactive Dashboard

The dashboard includes slicers for:
- Category
- Month
- Sales Channel

These filters allow users to interact with the dashboard and explore different aspects of sales performance.
